## IPLC 专线到底是什么

IPLC 全称 International Private Leased Circuit，即国际专用租用电路。它是运营商点对点出租的物理专线：国内一侧一台入口服务器，海外一侧一台出口服务器，两端之间走的是专线资源，不经过公共互联网。

这带来几个实际差异：

- **稳定性**：晚高峰公网国际出口拥堵、丢包飙升时，专线基本不受影响，因为它压根不在那条路上跑。
- **延迟**：专线线路端内延迟非常低。以 MKCloud 的产品资料为例，广港方向端内延迟 1~2ms，沪港 21ms，沪日 25~28ms，沪美 124~134ms。注意这些是端内参考值，不含你本地到入口、出口到目标网站的耗时。
- **内容审查干扰**：专线流量不与普通公网流量混跑，这也是为什么很多对线路质量敏感的业务会优先考虑它。

要说清楚一点：IPLC 本身是运营商一项正经的通信业务，企业跨境组网、电商访问海外后台、API 调用都是典型用途。但网上搜这个词的人里，相当一部分是冲着“翻墙机场专线”来的——市面上确实有不少机场拿 IPLC 当卖点卖翻墙线路，不过那是另一回事。本文讨论的是 MKCloud 这类合规商用专线产品，这类产品需要中国身份实名，明确禁止机场、回国等用途，违规会被清退且不退款。

## 下单前必须知道的几件事

这些限制直接影响购买决策，官方页面写得都很明白：

1. **实名与省级白名单**：所有产品需中国身份实名。直连款（IPLC/IEPL）采用省级白名单，只允许所选省份的 IP 连入，省份可自行切换；IX 款不限省份，但必须通过指定云厂网络连入。
2. **流量双向计费**：计量型套餐按上行+下行双向统计，超量后停机，可自助购买流量重置或提交工单补差价升级。估算用量时记得乘以二。
3. **共享带宽是峰值**：200M、300M 峰值不保证持续跑满，这一点官方也明说了。
4. **退款政策严格**：仅质量问题退款，且需要提交具体延迟、速度数据作为证据；开通后不支持更换地域。默认无 SLA 承诺。
5. **支付方式**：目前只支持支付宝。
6. **出口不能被连入**：出口 IP 只出站，不能用来架设对外网站、支付回调或游戏服务端。

系统支持方面比较全：Ubuntu、Debian、CentOS、AlmaLinux、Rocky、FreeBSD、Windows Server 等都有，开通为自动交付，官方口径约 1 分钟。

## 常见问题

**IPLC 专线一定比 IEPL 好吗？**

不一定。IPLC 和 IEPL 都是点对点专线，MKCloud 的广港 IEPL 端内延迟（1~2ms）甚至比沪日 IPLC（25~28ms）更低，因为香港物理距离近。选哪条主要看你人在哪个省、业务面向哪个市场，而不是产品名称。

**IPLC 专线一个月大概多少钱？**

以 MKCloud 为例，共享流量档起步价：沪港 ¥288、沪日 ¥358、沪美 ¥428；IXP 最低 ¥158；企业独享款从 ¥650 到数万元不等。市面上不同服务商价差很大，但“专线比普通 VPS 贵 10 倍”这种说法没有统一口径，具体要对比同配置、同流量额度下的价格。

**个人可以用吗？**

可以，实名后个人也能购买，用途限正规场景。但机场、回国等用途被明确禁止，发现即清退不退款。

**IPLC 买了就能保证业务不中断吗？**

不能。MKCloud 默认不提供 SLA 保证，需要 SLA、路由定制或高防参数要通过工单独确认。共享带宽的“峰值”也不等于持续保障，对连续性要求高的业务建议独享款并提前问清售后口径。

**IP 是原生的吗？能解锁流媒体吗？**

官方明确说明出口为服务器 IP，不保证原生、住宅属性或流媒体解锁。做店铺运营的用户建议先小流量档验证 IP 纯净度，再扩大用量。
